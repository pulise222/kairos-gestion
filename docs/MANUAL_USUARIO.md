# Manual de uso de Nivel

Para quien trabaja en el negocio. Si eres el dueño, lo tienes todo; si eres vendedor/a, ves **Venta**, **Ventas** (solo las tuyas), **Productos** (sin costos) e **Inventario** (solo el estado).

## Entrar y salir
Abre **Nivel** (acceso directo del escritorio o la dirección que te dieron en el celular/tablet), escribe tu usuario y contraseña y pulsa *Entrar*. Para salir, el botón de la **flecha** (barra lateral o arriba en el celular). Para cambiar tu contraseña, el botón de la **llave**.
Cada persona usa **su propio usuario**: así se sabe quién hizo cada venta.

## Vender
1. Ve a **Venta**. Busca el producto por **nombre**, **código** o **escaneando el código de barras**.
2. Toca el producto para agregarlo. Cambia las cantidades con **+ / −**.
3. En el cuadro del carrito elige el **medio de pago** y escribe cuánto te dieron (o toca un billete rápido). Verás las **vueltas**.
4. Pulsa **Confirmar venta**. El stock baja solo.

Si te equivocas **antes** de confirmar, pulsa **Cancelar venta**. Si no alcanza el stock, el sistema te avisa y te dice cuánto hay.
**No pulses dos veces** *Confirmar venta*: aunque lo hagas, se registra una sola venta.

## Si una venta salió mal
- **Se registró por error** (todo incorrecto): en **Ventas** abre la venta → **Anular esta venta** (solo el dueño), escribe el motivo. El stock vuelve.
- **El cliente devuelve algo**: en **Ventas** abre la venta → **Registrar devolución** (solo el dueño). Elige qué y cuántas unidades, si el producto está bien o dañado, y cómo se le devuelve el dinero. Se devuelve **al precio de esa venta**. Si está bien, vuelve al inventario.
- Una venta que ya tiene devoluciones **no se anula** (se sigue devolviendo lo que falte).

## Productos
- **Nuevo producto:** nombre, categoría y precio son lo básico. Puedes agregar **foto**, **descripción**, **proveedor**, **código** (propio, como `APEQ1`, o déjalo vacío y el sistema le pone un número) y el **stock mínimo** (para que te avise cuando se acabe).
- **Editar:** cambia lo que necesites, incluida la foto. Si cambias el precio o el costo, queda el historial. Las ventas viejas **no cambian**.
- **Desactivar:** el producto deja de aparecer en Venta pero su historial se conserva.
- **Importar desde Excel:** *Productos → Importar*. Descarga la plantilla, llénala, súbela y revisa la vista previa. Si hay errores te dice en qué fila y columna; mientras haya errores no se guarda nada.
- **Categorías:** *Configuración → Categorías* (crear, renombrar, color, desactivar).

## Inventario
- **Entrada de mercancía:** cuando llega un pedido (*Inventario → Entrada de mercancía*). Sube el stock y, si cambió el costo, lo actualiza.
- **Conteo físico:** *Inventario → Conteo físico*. Escribe lo que **hay** en cada producto (los vacíos no se tocan), revisa las diferencias y confirma. Cada diferencia queda con su motivo.
- **Ajustar un producto:** pérdida, daño o sobrante, siempre con un motivo.
- **Movimientos:** el historial de todo lo que subió o bajó el stock y por qué.
- El **stock no se escribe a mano**: solo cambia con ventas, entradas, devoluciones y ajustes, para que siempre se pueda explicar.

## Proveedores
Ahí ves qué pedirle a cada uno (lo que está bajo el mínimo). Si un proveedor trajo de más o mercancía mala, usa **Devolver mercancía**: sale del stock y queda registrado cuánto se le devolvió y cómo se resuelve (nota crédito, reembolso o reposición).

## Panel (dueño)
Ventas, ganancia, número de ventas, más vendidos y ventas por categoría. Cambia el **período** (hoy, ayer, 7 o 30 días, mes, o fechas a tu medida) y se compara con el período anterior. Las cifras ya **descuentan las devoluciones**.

## Copias de seguridad (dueño)
*Configuración → Copias de seguridad*. El sistema hace una copia **cada 24 horas** solo. Revisa que el semáforo esté **verde**. Puedes hacer una copia ahora, **descargarla** (guárdala en una USB o en tu correo) y restaurarla. **Restaurar borra lo registrado después de esa copia**: pídele ayuda a quien instaló el sistema la primera vez.

## Si algo no funciona
- *«No se pudo conectar con el servidor»*: el PC del negocio está apagado o cerró la ventana «Nivel · Servidor». Ábrela de nuevo.
- *«Sesión vencida»*: vuelve a entrar con tu usuario.
- *Un producto no aparece en Venta*: puede estar desactivado o con el filtro puesto en *Productos*.
- Para cualquier duda de las cifras, anota la hora y el producto y avisa a quien lo instaló.
